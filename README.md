# FLOWBUS — public demo

Энэ нь олон нийтэд үзүүлэхэд зориулсан HTML/CSS/JavaScript туршилтын хувилбар. Бодит GPS, баталгаажсан бүх маршрутын координат, production admin authentication, серверийн өгөгдлийн сан байхгүй. Feedback ба admin demo нь зөвхөн тухайн браузерт хадгалагдана. Бодит хувийн мэдээлэл оруулахгүй.

## Vercel
Шинэ зөвшөөрөлтэй project-д энэ хавтсыг Git repository-оор эсвэл Vercel CLI-аар холбоно. Framework preset: Other. Build command: хоосон. Output directory: үндсэн хавтас.

CLI: `npx vercel --prod` (өөрийн аккаунтаар нэвтэрч, зөв team/project сонгоно). Нууц .env файл оруулах шаардлагагүй.

Demo admin: demo. Энэ нь production authentication биш.
